# Задание №3 по веб-программированию

**Студент:** Ванчинова Дари

**Вариант:** 2 (Сохранение комментариев в базе данных)

## Что сделано:
- Страница "О себе" с блоком комментариев.
- Добавление комментариев работает без перезагрузки страницы (через DOM).
- Комментарии можно удалять.
- Все данные сохраняются в базу данных SQLite (файл `comments.db`).
- Бэкенд написан на Node.js (Express).

## Как запустить:
1. Скачать код.
2. Открыть терминал в папке с проектом.
3. Ввести команду `npm install` (чтобы скачались нужные библиотеки).
4. Ввести `node server.js`.
5. Открыть в браузере ссылку: http://localhost:3000

*База данных создастся сама при первом запуске.*
